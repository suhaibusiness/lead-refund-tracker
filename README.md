# Lead Refund Tracker

Track every lead you pay Angi, Thumbtack, Google Local Services, Bark, hipages or Yelp for, and claim back the ones their own rules allow. Free beta.

Live: https://suhaibusiness.github.io/lead-refund-tracker/

This repository holds the built static site only. It is published by `deploy/deploy.ps1` from the source folder `gap-hunt/build/lead-ledger`; edits made here are replaced on the next deploy.
